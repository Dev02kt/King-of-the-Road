# King of the Road

This project’s goal is to develop a single/multiplayer racing game that anyone can play in the browser. This project is being developed by four college students for their Computer Science III course. It serves as an opportunity to test and extend individual capabilities as programmers, and is a practical way of getting real software development experience when working with a team.

## Description

King of the Road is a top-down online single/multiplayer browser-based game with a maximum of four players. It features four separate cars and one long road upon which they drive. The player(s) will control their own individual car(s) in an endless deathrace until only one is left racing. Players will have a choice of joining a random lobby or their own lobby codes if they want to play with friends. CPUs will control the remaining car(s) if there are less than four players in the game. The game will feature a heart system where each car will begin the game with three gas tanks, and explode upon losing all three tanks. A tank will be lost when a car collides with an obstacle on the road. Additionally, the game will feature a power-up system where pick-ups can be driven through to grant special effects or powers for players to use on either their enemies or themselves. As the game's runtime increases, the speed of the cars will slowly accelerate to add another layer of difficulty. When there is only one car remaining on the road, that player will be crowned as the King of the Road, and a game summary screen will be displayed shortly afterwards, marking the end of the game.

## Dependencies

### Runtime

* **None** — Built entirely with Java, libGDX, AWS, and SpringBoot
* **Web Browser** — Any modern browser (Chrome, Firefox, etc.)
